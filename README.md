# DARKTG

DARKTG is migrating from Flutter/TDLib to a native Android client based on [Telegram-FOSS](https://github.com/Telegram-FOSS-Team/Telegram-FOSS).

See [native/README.md](native/README.md) for cloning, API key setup, Ghost Mode patching, and build instructions.

The \`native-migration\` branch is the migration workspace. The previous Flutter implementation remains preserved on \`main\`.
